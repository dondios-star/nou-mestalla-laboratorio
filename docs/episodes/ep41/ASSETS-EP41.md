## Derechos y publicación

Ningún píxel de las fotografías ni del esquema aportados se incorpora al MP4. Se consultan para geometría/periodo. El archivo de 2013 tiene una fuente coincidente con licencia CC BY-SA 3.0; las demás fotos no tienen permiso documentado. La autorización de estudiar los archivos no se presenta como una licencia de sus autores.

El modelo tridimensional es procedural propio: hormigón, forjados abiertos, tres bancos de grada, pilares y coronación recortada. Es una aproximación visual, no un modelo BIM ni un plano de ejecución. El contexto urbano es sintético; no documenta cada edificio o árbol real. La fase B es un paquete de subestructura ilustrativo que el supuesto didáctico considera financiado y cerrable, no una fase constructiva real validada.

El aficionado es enteramente ficticio, generado en esta tarea con Image Generation: `video/public/assets/ep41/aficionado-tres-edades.png`, 1536×1024 RGBA. Se conserva la ficha original y se usan ventanas CSS de 512 px; no se retocaron caras ni se extrajeron personas reales. Es una capa 2D en escenario 3D, no un personaje riggeado. Sin logos de clubes ni textos generados. Prompt: mismo aficionado castaño a 9/17/24 años, pose consistente, manos en bolsillos, bufanda blanquinegra con franja naranja, luz diurna y transparencia.

Marca: referencia-marca-alberto.png inspeccionada. Se reutilizan tokens y fuentes Anton/Inter locales (OFL; licencias en public/fonts). No se incrusta la lámina completa. Bufanda de transición: gráfico propio CSS. Interfaz de correo y maqueta: código propio. No hay voz, música ni efectos; el máster está sin audio.
