# Recursos propios del episodio 45

`stadium.jpg`: render fijo de `Stadium.tsx`.
`hero.mp4`: fila y cinco personajes, 270 frames a 60 fps.
`sector-{A,B,C}.mp4`: animaciones de 330 frames; se congela el estado final durante lectura.
`sector-{base,A,B,C}.png`: estados finales, también utilizados en miniaturas.

Se regeneran con `npm run ep45:assets` desde `video/`. No contienen fotografías o renders comerciales. Fuentes de geometría, materiales y movimiento en `video/src/episodes/ep45/`. No son modelos BIM o planos técnicos. Todo el render utiliza archivos locales.
